*Medallion Pipeline & AI Prescription Digitizer*

![PySpark](https://img.shields.io/badge/PySpark-E25A1C?style=flat-square&logo=apachespark&logoColor=white)

Generative AI in production, converting unstructured prescription images into query-ready analytical tables.
