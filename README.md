### 🩺 [MedScan](https://github.com/sarthakgoyal2705/medscan) — [live demo →](https://medscan-mzny.onrender.com)

Digitizes handwritten prescriptions and finds cheaper Indian generic equivalents.
Vision model reads the prescription, fuzzy salt-signature matching runs it against
246k products, and the app surfaces same-salt alternatives plus the nearest of
18,673 Jan Aushadhi stores.

`FastAPI` · `Gemini Vision` · `rapidfuzz` · `SQLite` · EN/Hindi UI

### 🧬 [BioPath RAG](https://github.com/sarthakgoyal2705/multimodal-rag)

Multimodal RAG research assistant for biological literature. Reads both text and

`LlamaIndex` · `Groq (llama-3.1-8b)` · `Gemini embeddings` · `FastAPI` · `Next.js`
